# TaskFlow — Project Statement

## Problem Statement
Students and individuals rely on scattered notes, sticky pads, or unstructured text files to track tasks. There is no consistent format, priority ordering, or due date tracking. Pending and overdue tasks are easily missed, and there is no way to measure completion rate or productivity over time.

TaskFlow addresses this by providing structured, validated, and persistent task management through a Java command-line application.

## Scope of the Project
Included:
- Create, view, update, filter, and delete tasks
- Filter by status and priority
- Productivity reports with completion rate
- Persistent local storage using CSV

Excluded:
- Cloud synchronization
- Multi-user support
- Reminders or notifications
- GUI or mobile app

## Target Users
- College students managing assignments
- Individuals who prefer terminal utilities
- Java learners studying OOP and file handling

## High-Level Features
1. Task Management — Create, view, update, and delete tasks
2. Priority and Status Enums — Type-safe handling of task attributes
3. Reporting Module — Calculates totals and completion rates
4. Persistence Module — Reads and writes data/tasks.csv
